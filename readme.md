# 🚀 Magzant

> Creative Digital Agency Website built with React & Vite.

Magzant is a modern digital agency website showcasing our creative services including Graphic Design, Digital Marketing, Website Development, Branding, and Business Solutions. The website is designed with a clean UI, responsive layouts, smooth animations, and an optimized user experience.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/isuprotikroy/Magzant.git
```

Go to project folder

```bash
cd Magzant
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
